Use these two steps on your website. Replace YOUR_CUSTOMER_API_KEY with your key from the dashboard.

1) Create /pn-sw.js at your site root:

⚠️ Important: This must be in a separate file, not in your HTML!

Option A: Download the ready-to-use file:

📥 Download pn-sw.js 📥 Backup Download

Option B: Create the file manually with this content:

importScripts('http://13.126.228.42/pn-sw.js');

2) Add SDK + init before </body>:

<script src="http://13.126.228.42/sdk.js" data-api-key="YOUR_CUSTOMER_API_KEY"></script>
<script>
  PN.init({ baseUrl: 'http://13.126.228.42', serviceWorkerUrl: '/pn-sw.js' });
</script>

Tip: You can pass the API key programmatically as well:

PN.init({ apiKey: 'YOUR_CUSTOMER_API_KEY', baseUrl: 'http://13.126.228.42', serviceWorkerUrl: '/pn-sw.js' });
