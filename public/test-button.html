🔔 Push Notification Button Test

Auto-Init Button (Data Attributes)

This button initializes automatically when the page loads:

<script src="http://localhost:4000/push-button.js"></script> <button data-push-button data-auto-init data-api-key="demo-api-key" data-base-url="http://localhost:4000" data-theme="gradient" > 🔔 Enable Push Notifications </button>

Manual Init Button (JavaScript)

This button is initialized with JavaScript:

new PushNotificationButton({ selector: '#manual-button', apiKey: 'demo-api-key', baseUrl: 'http://localhost:4000', theme: 'primary', onSuccess: function(result) { console.log('Success!', result); } });
